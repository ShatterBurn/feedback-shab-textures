# Prospector's Pick

A small pick on a haft that shows whether a block bears metal.

## Crafting

Shape a **Prospector Head** from a rod or an ingot at a bench (the [Smithing Table](Smithing_Table.md) for metal), then put it with a haft and a tool binding in a crafting grid; it is a [hafted tool](Hafted_Tool.md) whose face is a prospector head. A harder piece can be set in the head's edge slot. The head's material sets how long the pick lasts.

## Using it

Right-click a block. The block is not harmed.

- A block that bears metal (an [ore](Ores.md)) throws glints off the face you struck, each metal in its own color. More glints fly where a piece of the block yields more ingots.
- A block that bears nothing puffs plain gray dust.

Each use wears the pick.

## How it works

The head's **point** axis trades what you see against wear. A finer point shows more glints and wears faster; a blunt one shows fewer and wears less.
