# USB Port

A socket you fit to a [Computer](Electric_Controller.md#computer). With it fitted, the Computer's drive bays, running slot and editor take [USB Drives](Programming.md#media) as well as Floppy Disks.

## Crafting

```
K K K
K P K
```

K is a Ceramic and P is a Copper Plate. Craft it at the [Engineering Table](Engineering_Table.md) with a [screwdriver](Hand_Tools.md#screwdriver) in the tool row, 2 machine bolts ([Fasteners](Fasteners.md)) and Electrical Treatise III: Circuits ([Treatise](Treatise.md)).

## Using it

Use it on a Computer to fit it. A Computer carries one USB Port.
