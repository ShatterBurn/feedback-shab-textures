# Tether Reel

A reel on an [electrical](Electricity.md) line that feeds a [robot](Robots.md) tied to it by a Tether Cable, for as long as the robot stays within the cable's length.

## Crafting

Tether Reel:

```
 P S P
 W P W
```

P is a [Copper Plate](Mechanical_Hammer.md), S is string and W is [Copper Wire](Wire_Drawer.md). Craft it at the [Engineering Table](Engineering_Table.md) with a [screwdriver](Hand_Tools.md#screwdriver) in the tool row and 2 [fasteners](Fasteners.md), holding Robotics Treatise II: Robots ([Treatise](Treatise.md)).

Tether Cable:

```
 W S W
```

The cable is crafted the same way, with no fasteners.

## Using it

1. Use the Tether Cable on the reel to take that end. The bar shows *"Cable taken to the reel"*.
2. Use the cable on the robot. The bar shows *"Robot tied to the reel"*.
3. Sneak and use the cable on the robot to untie it (*"Robot untied"*).

A tied robot is charged off the line like a robot on a [Robot Dock](Robot_Dock.md), and may roam only so far from the reel; it stops rolling at the end of the cable. A removed reel leaves the robot untied. Using the cable on a robot before taking a reel's end shows *"Use the cable on a reel first"*.
